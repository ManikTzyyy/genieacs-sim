# genieacs-sim

TR-069 client simulator for GenieACS.

To install:

    git clone https://github.com/zaidka/genieacs-sim.git
    cd genieacs-sim
    npm install

    chmod +x run-all-csv.sh stop-all-csv.sh


Generate device:

    node generate.js

To run:
    ./run-all-csv.sh

To stop:
    ./stop-all-csv.sh


Help:

    ./genieacs-sim --help
